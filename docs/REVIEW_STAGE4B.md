## Point-by-point answers

1. **Graphemes:** correct for Mn/Mc/Me + surrogate pairs + VS16 + ZWJ/ZWNJ + CR/LF + Hangul L·V·T. **Not** covered: emoji modifiers (Sk), regional indicators, prepend — not typeable with our 15 layouts (all space-separated Latin/Cyrillic/Greek, emoji only as an action key) ⇒ no practical harm today (A-3).
2. **InputConnectionSink:** UTF-16 units correct, `beginBatchEdit`/`endBatchEdit` in `finally` (all paths), null connection → `EditorUnavailableException`/`null` (no crash), no `setComposingText`, no text logs. Partial editor inconsistency on a commit failure is fail-closed (A-5).
3. **Ownership/controller:** after a foreign input permanently no writing (`lost=true`, `isOwned` false) ✓; generation/session guard: `sessionId` watertight (`applyPartial`/`stop` discard foreign sessions) ✓, `runId` decorative (A-2); `abort()` total to IDLE ✓; `min_audio_s=2.0` **only** for partials, final always decodes ✓ (tests `partialsBelowMinAudio…`/`finalDecodeRunsEvenBelowMinAudio` prove it).
4. **State machine:** transitions total (IDLE→STARTING→RECORDING→FINALIZING→IDLE; double start no-op; STARTING synchronous-transient; `abort`/`fail` → IDLE). **Gap:** editor switch during RECORDING does not abort (A-1).
5. **ModelStore/downloader:** SHA-256 exact (B-3, 4/4 compared); resume 206/200/ETag/digest/prefix/atomic activation/traversal/disconnect/disk space/no OkHttp all present — **except** B-1 (416) and B-2 (no downloader test).
6. **Safety/privacy:** no writing outside the store tree (`safeChild` canonicalization+whitelist) ✓, no URL/content logs (`DownloadProgress` only bytes/rate) ✓; INTERNET removal vs. downloader = staging, to be resolved cleanly via "permission only on wiring" (B-4).
7. **Test quality:** genuine cross-checks (`partialsBelowMinAudioAreNotDecoded`, `lateResultOfOldSessionIsDiscarded`, `foreignSelectionBlocksFurtherWrites`, `activate bricht ab bei unvollständiger Staging Version`). **Revert-to-red:** reverting the `ModelDownloader` would turn **no** test red (B-2); reverting `session isolation`, the `min_audio` guard or `ownership-lost` **would** turn red (controller/tracker tests). Graphemes tests cover ZWJ/combinations, not Sk/RI (consistent with A-3).
