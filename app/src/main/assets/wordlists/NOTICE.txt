Modifications (Bearbeitungsvermerk):
  - filtered to letter-only word forms (incl. umlauts / eszett), length >= 2
  - case-insensitive deduplication (most frequent spelling kept as main form)
  - cut-off to the most frequent forms: de-de top 100,000 / en-us top 150,000
    (T23b sweep decision, see tools/wordlists/SWEEP_de.md / SWEEP_en.md)
  - stoplist subtraction (curated stop lists — see
    tools/wordlists/stop_de.txt / stop_en.txt, 1267 / 660 bytes incl.
    'strasse', 'bud'; VK-7 wording correction REVIEW_V0147)
  - repacked into the deterministic VKWL1 binary format
    (format documented in tools/build_wordlist.py)

Rebuild (bit-identical, same input + stoplist):
  python3 tools/build_wordlist.py build de-de tools/wordlists/de_full.txt \
      --stop tools/wordlists/stop_de.txt --top 100000 \
      --out app/src/main/assets/wordlists/de-de.bin
  python3 tools/build_wordlist.py build en-us tools/wordlists/en_full.txt \
      --stop tools/wordlists/stop_en.txt --top 150000 \
      --out app/src/main/assets/wordlists/en-us.bin
